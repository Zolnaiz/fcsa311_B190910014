2-р даалгавар — ArrayIntQueue bug засах
Bug 1 — isEmpty() буруу байсан

Өмнөх код:

return size >= 0;

Энэ нь үргэлж true буцааж байсан.

Зассан:

return size == 0;

Bug 2 — peek() empty queue дээр буруу ажиллаж байсан

Зассан:

public Integer peek() {
    if (isEmpty()) {
        return null;
    }
    return elementData[head];
}
Bug 3 — ensureCapacity() circular queue copy logic буруу байсан

Wrap-around болсон үед array resize хийхэд дараалал алдагдаж байсан.

Зассан:

for (int i = 0; i < head; i++) {
    newData[oldCapacity - head + i] = elementData[i];
}
