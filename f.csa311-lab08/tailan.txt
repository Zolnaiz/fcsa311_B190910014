Хийсэн logic
Card бүрийн хамгийн сүүлийн result-ийг авсан.
Хамгийн сүүлд буруу хариулсан card-уудыг эхэнд гаргадаг болгосон.
Зөв хариулсан болон буруу хариулсан card-уудын дотоод дарааллыг хадгалсан.
Гол logic
const aLastWrong = aResults.length > 0 && !aResults[aResults.length - 1]
const bLastWrong = bResults.length > 0 && !bResults[bResults.length - 1]

if (aLastWrong === bLastWrong) {
  return 0
}

return aLastWrong ? -1 : 1
