## Coding Convention
- Use TypeScript for frontend.
- Use Express.js for backend.
- Use simple and readable function names.
- Use Conventional Commits.

## No-Go Zones
- Do not commit secrets.
- Do not hardcode API keys.
- Do not delete tests.
- Do not push node_modules manually.
- Do not generate code that cannot be explained.
