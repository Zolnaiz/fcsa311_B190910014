# ADR-0001 Stack Decision

## Status
Accepted

## Context
The project required a simple but modern full-stack architecture for demonstrating AI-assisted development.

## Decision
The project uses:
- React + TypeScript frontend
- Express.js backend

## Reason
This stack allows:
- Fast development
- Easy debugging
- Simple frontend/backend integration
- Good support from AI coding assistants

## Consequences
The project is lightweight and easy to maintain, but not intended for large-scale production use.
